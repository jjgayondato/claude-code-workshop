# KZ-105 Show how long tickets sit in each step (bonus)

Reporter: Daniel (TL) · SDLC step: all steps

## Story
As a TL, I want each card to show how many days it has been in its current step,
so that I can see where tickets get stuck.

## Acceptance criteria
1. The badge counts calendar days from when the ticket entered its step until now.
2. The badge never shows "null" or "NaN".
3. Tests use a fixed date, never the real clock.
4. Open question for the TL: working days and Malaysian public holidays? (not in this change)
