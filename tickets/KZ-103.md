# KZ-103 Infra approval before deploy

Reporter: Daniel (TL) · SDLC step: 10 Production deployment

## Story
As Infra, I want to be the only role that can approve a production deploy,
so that every release passes through us.

## Acceptance criteria
1. Only a user with the Infra role can approve a deploy (an allow list).
2. A BA, a TL and a developer are refused, with a clear message.
3. Only a ticket in Pending Production can be approved.
