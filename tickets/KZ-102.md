# KZ-102 Send failed tickets back to the developer

Reporter: Aisyah (BA) · SDLC step: 8 Staging testing ("Issue? Yes" back to 5)

## Story
As a BA, I want to send a failed ticket back to development with a reason,
so that the developer knows what to fix and the fix is reviewed again.

## Acceptance criteria
1. Only a ticket in Staging Testing can be sent back. It goes to In Progress.
2. A reason is required.
3. The old code review approval is cleared. The ticket needs a new approval
   before it can reach Staging Testing again.
4. The ticket keeps the same assignee.
